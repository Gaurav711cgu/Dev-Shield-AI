# 🛡 DevShield AI Governance Platform

DevShield is an AI-powered backend API for autonomous code risk analysis and governance monitoring.

## 🚀 Features

- Risk scoring engine
- Threat severity classification
- Rolling risk index
- Demo simulation mode
- Real-time dashboard API
- Executive report generation

## 🏗 Architecture

Frontend (React/Lovable/etc)
        ↓
Flask API (Render)
        ↓
SQLite Database

## 📡 API Endpoints

### Analyze Code
POST `/api/analyze`

### Dashboard Data
GET `/api/dashboard`

### Demo Data Generator
GET `/api/demo`
